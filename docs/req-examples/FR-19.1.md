# FR-19.1 — I/O behind a load-once branch is no N+1 (PHP)

```php
class Settings
{
    private static bool $loaded = false;
    private static array $values = [];

    public static function get(string $key): mixed
    {
        if (!self::$loaded) {                  // load-once branch
            self::$values = Http::get(config('settings.url'))->json();
            self::$loaded = true;
        }
        return self::$values[$key] ?? null;
    }
}

class TaxService
{
    public function rates(array $countries): array
    {
        $rates = [];
        foreach ($countries as $country) {
            $rates[$country] = Settings::get("tax.$country");   // the HTTP call runs once
        }
        return $rates;
    }
}
```

The HTTP call is reached only through `if (!self::$loaded)`, so the loop in `TaxService::rates` gets no *I/O in a loop* finding.
