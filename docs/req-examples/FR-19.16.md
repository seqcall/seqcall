# FR-19.16 — callbacks are no step back (TypeScript)

```ts
// paging.ts (Domain): knows nothing about who fetches
export async function all<T>(fetch: (page: number) => Promise<T[]>): Promise<T[]> {
  const items: T[] = [];
  for (let p = 1; ; p++) { const page = await fetch(p); if (!page.length) return items; items.push(...page); }
}

// client.ts (Infrastructure)
export const client = {
  listInvoices: () => all((p) => client.getPage('/invoices', p)),
  getPage: (path: string, p: number) => http.get(`${path}?page=${p}`),
};
```

`client → paging.all(fetch) → client's lambda → client.getPage` is drawn (the lambda's calls are the client's),
but it is no *Cyclic collaboration*, no *Layer ping-pong* and no *Dependency cycle*: `all` only calls the
function it was handed.
