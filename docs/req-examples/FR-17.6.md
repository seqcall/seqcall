# FR-17.6 — I/O of an interface call with several implementations (C#)

```csharp
public interface IMapsApi { Task<Route> PlanRouteAsync(RouteRequest r); }

public class ParcelApiClient : IMapsApi          // does HTTP
{
    public Task<Route> PlanRouteAsync(RouteRequest r) => _http.PostAsJsonAsync("/routes", r) /* … */;
}

public class OfflineMapsClient : IMapsApi      // a stub: left out
{
    public Task<Route> PlanRouteAsync(RouteRequest r)
    {
        throw new NotImplementedException();
    }
}

public async Task PlanAndSaveAsync(RouteRequest r)
{
    var route = await _maps.PlanRouteAsync(r);  // IMapsApi, no implementation chosen
    await _db.Routes.AddAsync(route);           // DB
}
```

The collapsed `PlanAndSaveAsync` shows `DB HTTP`: the only real implementation does HTTP. If a second real
implementation did no HTTP, the HTTP pill would not be shown.
