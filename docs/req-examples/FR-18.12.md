# FR-18.12 — a trait's `$this` is the class using it (PHP)

```php
trait SavesOrders
{
    public function saveOrder(Order $order): void
    {
        $this->reserveStock($order);   // declared only in OrderManager, not in the trait
        $order->save();
    }
}

class OrderManager
{
    use SavesOrders;

    private function reserveStock(Order $order): void
    {
        Stock::reserve($order->items);
    }
}
```

In the flow of `saveOrder`, `$this->reserveStock()` is a call to `OrderManager::reserveStock` (the only class using
the trait). *Paths to here* of `OrderManager::reserveStock` lists `SavesOrders::saveOrder` as its caller.
