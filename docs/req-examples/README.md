# Requirement examples

Short, made-up code samples for requirements in [FUNCTIONAL-REQUIREMENTS.md](../FUNCTIONAL-REQUIREMENTS.md)
whose rule is easier to follow with a concrete case. One file per requirement (`FR-<id>.md`), linked from its row.

Rules for this folder:

- Neutral names only (shop, order, invoice, coupon …). Never code, names, routes or numbers from real or
  private projects.
- Keep each sample to the shape the rule is about, plus 1–3 lines on what Seqcall shows.
