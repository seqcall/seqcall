# FR-18.11 — routes of a first-party package mounted by the project (PHP / Laravel)

```php
// vendor/acme/shop-orders/src/RouteRegistrar.php (first-party package)
class RouteRegistrar
{
    private ?string $controller = OrdersController::class;

    public function __construct(private Router $router) {}

    public function registerShopRoutes(string $version): void
    {
        $this->router->group(['prefix' => $version], function () {
            $this->router->get('orders/{id}', [$this->controller, 'show']);
        });
    }
}

// routes/api.php (the project)
Route::group(['prefix' => 'shop'], function () {
    app(RouteRegistrar::class)->registerShopRoutes(ApiVersions::V2_PREFIX);   // 'v2'
});
```

Listed entry point: `GET /api/shop/v2/orders/{id}` → `OrdersController.show` (`route · acme/shop-orders`).
Routes of the package that the project does not mount are not listed.
